# 中文生产模板与质量门

仅在实际制作海报时读取本文件。每张照片都要先完成“原图理解卡”，再填写提示词；方括号内容必须换成本轮照片的真实信息。

## 原图理解卡

```text
可见主体：[人物、动物、植物、器物、建筑、环境]
身份锚点：[脸、花纹、轮廓、材质、服装、姿势]
核心关系：[谁与谁 / 什么与什么，以何种距离、动作或反差发生关系]
最值得记住：[一句话，只写画面真正讲的事]
必须保留：[下半区仍须可识别的主体、动作与空间关系]
可以舍弃：[不支撑寓意的背景信息]
禁止新增：[原图无法支持的真实人物、动物、产品或象征物]
文案方向：[念头、画外音、反转或双关；不直接命名物体]
```

判断顺序必须是：关系与动作 → 情绪或反差 → 真实锚点 → 涂鸦动作 → 文案。不要从“最大物体”开始。

## 首选：下半区 3:2 面板提示词

```text
Use case: style-transfer
Asset type: 单张 3:4 编辑海报的下半区，独立 3:2 横向面板
Input image: 上传照片是唯一身份、材质、姿态与叙事参考

Primary request:
把原图最值得记住的意思——“[最值得记住]”——重构为高级独立出版物式编辑画面。不要复述整张照片，也不要机械截取最大物体。

Scene/backdrop:
[米白 / 暖白 / 从原图提取的舒适浅色]纸面背景，大量留白，干净、轻快、克制。

Photoreal anchors:
以真实摄影质感保留[必须保留的全部关系主体]。准确延续[身份锚点]、[核心姿态]与[空间关系]；可删除[可以舍弃]，但不得把关系主体缩成爪子、袖口、阴影或无身份碎片。若原图没有人物或动物，真实锚点必须仍能直接追溯到原图，禁止发明[禁止新增]。

Doodle micro-story:
加入 2–3 个极小、稚拙、纤细的黑线涂鸦小人。他们分别[动作一]、[动作二]、[可选动作三]；动作必须回应真实主体的轮廓、重量、方向、距离或反差。小人只做叙事辅助，不遮挡脸、眼睛、关键花纹或连接关系。

Text (verbatim):
“[极短中文文案]”
只出现一次，逐字正确，以松弛的小号黑色手写字沿[轮廓或留白节奏]排布，像一句私密画外音，不像居中标题。

Color and finish:
从原图提取[主色]、[辅助色]与[深色线条]；真实主体承担主要色彩，涂鸦与文字使用黑色或深灰细线。生活方式杂志、艺术摄影、独立 zine 质感，真实材质与自然光影。

Hard constraints:
一个 3:2 面板；所有关系主体完整可识别；身份不漂移；解剖正确；无额外真实人物或动物；无无依据象征物；无卡通主体；无贴纸感；无复杂装饰；无模板标题；无 Logo、水印、边框或多余文字。
```

## 上半区与最终组装

1. 直接使用原照片制作 3:2 上半面板。优先裁掉无关背景；空间不足时只自然扩展环境。不得拉伸、换脸、改变动物花纹或重新摆拍。
2. 只做轻微高级摄影调色：保持原有自然光影、真实材质和色彩氛围。
3. 将上半 3:2 原图面板与下半 3:2 生成面板垂直拼接。两者像素高度必须完全相同。
4. 最终文件必须是精确 3:4，分界线位于 `H / 2`。

如果环境只能一次生成整张海报，把上面两段合并为一个提示词，并重复写明：`one exact 3:4 poster; boundary at exactly 50% height; upper panel is the faithful source photograph; lower panel is the reinterpretation`。生成后仍必须测量并校正画布。

## 文案筛选

文案符合以下形状：

- 6–14 个汉字优先；
- 是念头、旁白、轻反转或双关；
- 能脱离物体名称仍成立；
- 不解释构图，不使用品牌口号语气；
- 一张海报只出现一句。

不合格：`一把红伞`、`温馨陪伴`、`美好的一天`。

合格示例：两人在暴雨中挤在破伞下，可写 `雨太大，那就靠近一点`。真实锚点仍是两个人与破伞；不能凭空替换成汤碗、房屋或其他“温暖”符号。

## 最终质量门

### 语义

- 缩略图第一眼读到的是原图的动作或关系，而不是最大物体。
- 下半区是可追溯的二次解读，没有添加原图不支持的真实故事道具。
- 每个涂鸦动作都能回答“它在回应原图的什么”。

### 身份与结构

- 人脸、动物花纹、姿势和关键材质与原图一致。
- 关系由多人或人宠共同构成时，下半区每个主体都清楚可辨。
- 没有多余肢体、重复头部、错位爪子或遮挡关键脸部。

### 版式

- 文件宽高满足 `W × 4 = H × 3`。
- 高度为偶数；上下各为 `H / 2`。
- 上下都是 3:2 面板；无额外分栏、拼贴或边框。
- 留白占下半区主要空间，小人与文字不抢真实主体。

### 文字与文件

- 文案逐字核对，只出现一次，无乱码或多余文字。
- 文件可解析，目标目录中采用版本化名称，未覆盖来源照片。
- 最终回复报告保存路径、使用的提示词和验证结果。

## 迭代规则

一次只修一个缺陷：先身份与关系，再解剖，再版式比例，再文字，最后才是细小风格差异。若必须重做，保留已通过的约束并在新提示词中逐项重申。
